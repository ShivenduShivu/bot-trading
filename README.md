# 📈 Paper Trading Platform

A production-ready paper trading platform for manual and algorithmic trading.

## Current Status: Checkpoint 0 ✅
- Backend: FastAPI server setup
- Frontend: React + Vite setup
- Basic "Hello World" connection established

## Tech Stack
- **Backend**: FastAPI (Python)
- **Frontend**: React 18 + Vite
- **Future**: PostgreSQL, Docker, WebSockets

## Getting Started

### Backend Setup
```bash
cd backend
python -m venv venv
venv\Scripts\activate  # Windows
pip install -r requirements.txt
python main.py
```
Backend runs at: http://localhost:8000

### Frontend Setup
```bash
cd frontend
npm install
npm run dev
```
Frontend runs at: http://localhost:5173
